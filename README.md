# R-Match

**R-Match** — Android-приложение футбольной аналитики от **Roger&Michin Studio**.

Приложение работает только с **реальными данными API-Football.com / API-Sports** и не использует демо-матчи, вымышленные составы, искусственные коэффициенты или scraping сторонних сайтов.

## Источник данных

- API: https://www.api-football.com/
- Dashboard: https://dashboard.api-football.com/
- Base URL: `https://v3.football.api-sports.io/`
- Header: `x-apisports-key`

## Как получить и использовать API key

1. Зарегистрируйтесь в API-Sports / API-Football.
2. Получите персональный `x-apisports-key` в dashboard.
3. При первом запуске введите ключ в onboarding и нажмите **«Сохранить и проверить»**.
4. Приложение реально проверит ключ через API и сохранит его локально в `ApiKeyStore` через `EncryptedSharedPreferences`.
5. В дальнейшем ключ автоматически используется, в UI показывается только в маскированном виде.

> Ключ **не должен** попадать в Git, BuildConfig, Room, README, CI, workflow secrets для сборки этого проекта или логи.

## Что умеет приложение

- Тёмный русский спортивный UI на **Kotlin + Jetpack Compose + Material 3**.
- Нижняя навигация: **Матчи / Лиги / Аналитика / Эфир / Настройки**.
- Работа без ключа только в честном onboarding-режиме — без демо-данных.
- Реальные endpoints API-Football по доступности тарифа: `countries`, `leagues`, `leagues/seasons`, `fixtures`, `fixtures/events`, `fixtures/statistics`, `fixtures/lineups`, `standings`, `teams`, `teams/statistics`, `players`, `players/squads`, `coachs`, `injuries`, `odds`.
- DTO → mapper → domain.
- Room-кэш с TTL, показом источника и stale/cache времени.
- DataStore для пользовательских фильтров.
- Настройки: статус API, попытка получить квоту из headers, проверка подключения, смена ключа, удаление ключа с подтверждением и очисткой кэша, очистка кэша.
- Вкладка **«Эфир»** сообщает, что поддерживаются только будущие официальные ссылки правообладателей.

## R-Match Analyst

`R-Match Analyst` — прозрачный детерминированный модуль, а не генератор выдуманных советов.

- При наличии минимум 5 завершённых матчей у каждой команды применяется документированная **Poisson-модель**.
- Учитываются реальные последние матчи, форма дома/в гостях, таблица, подтверждённые травмы и факт публикации составов.
- Публикуются вероятности 1X2, ожидаемые голы, тоталы, BTTS и форы.
- При наличии свежей и полной линии из `/odds` рассчитываются implied probability, нормализованная рыночная вероятность без overround и delta `model-market`.
- Если данных мало, приложение честно пишет: **«Недостаточно данных для расчёта»**.

> Вероятности не гарантируют исход и не являются финансовой рекомендацией.

## Ограничения и принципы

- Только реальные данные API-Football / API-Sports.
- Нет scraping, обхода robots.txt, CAPTCHA, paywall, auth, rate limits или геоблокировок.
- Нет пиратских трансляций, IPTV или неофициальных плееров.
- Если провайдер не вернул данные, UI показывает состояния: `Нет верифицированных данных`, `Составы пока не опубликованы поставщиком`, `Недостаточно данных для расчёта`, `Коэффициенты недоступны`, `Лимит API исчерпан`.

## Локальная сборка

Требования:

- JDK 17
- Android SDK 35
- minSdk 26 / targetSdk 35

Команды:

```bash
./gradlew test
./gradlew :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Free API limits и кэш

Бесплатные тарифы API-Football могут жёстко ограничивать квоту и покрытие endpoints. Поэтому приложение:

- кэширует ответы в Room с TTL;
- показывает stale/cache время;
- не делает вид, что знает данные, которых нет у провайдера;
- работает без API key только как onboarding.

## Production warning

Для production-окружения безопаснее использовать **backend proxy**, а не прямой API key в клиентском приложении.
